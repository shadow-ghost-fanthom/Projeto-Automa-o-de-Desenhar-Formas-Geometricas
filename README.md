# Script em Python que automatiza o desenho de formas geométricas no Microsoft Paint usando a biblioteca PyAutoGUI.

🛠️ O que ele faz:
Automação completa: Abre o Paint sozinho pelo menu Iniciar.
Formas Geométricas: Desenha Quadrados, Triângulos e Círculos.
Trigonometria: Usa cálculos de Seno e Cosseno (math) para criar círculos perfeitos.
Interatividade: Possui menus para escolha de formas e tamanhos.

🚀 Tecnologias:
Python 3
PyAutoGUI (Automação de interface)
Math (Cálculos geométricos)

📖 Como rodar:
Instale a biblioteca:
```bash
pip install pyautogui
```
Execute o script e escolha a forma no menu.
Deixe o robô trabalhar!
